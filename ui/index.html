Ornith CLI & Interactive Coding Agent

                  
Install the standalone ornith CLI on any machine, choose how you want to authenticate (Developer Account via Resend 6-digit code OR API Key), and use it directly for coding.

                

                v2.5 Ready
              


              
Step 1 — Install the CLI & Add to Current Shell PATH

              
Click Copy on any command below to copy the exact runnable command:

              

                

                  Install ornith to ~/.local/bin/ornith and activate PATH in your current terminal:
                  

                    curl -fsSL https://kusi-qwen-api.vercel.app/install.sh | bash && export PATH="$HOME/.local/bin:$PATH"
                    
                  

                

                

                  If an older terminal tab ever says command not found, refresh its PATH:
                  

                    export PATH="$HOME/.local/bin:$PATH"
                    
                  

                

              


              
Step 2 — Authenticate (Choose Account Login or API Key)

              

                

                  Interactive login selector (choose [1] Email + 6-Digit Resend Code or [2] API Key):
                  

                    ornith login
                    
                  

                

                

                  Or sign in directly with your Developer Account email:
                  

                    ornith login --account 2024frank@gmail.com
                    
                  

                

                

                  Or sign in directly with a Secret API Key:
                  

                    ornith login --api-key sk-ornith-YOUR_KEY
                    
                  

                

                

                  Verify your active account and connection status:
                  

                    ornith whoami
                    
                  

                

              


              
Step 3 — Coding Agent, Chat, Image Generation & Sandbox

              

                

                  Start interactive coding agent REPL in your current project folder:
                  

                    ornith code
                    
                  

                

                

                  Run a one-shot autonomous coding task:
                  

                    ornith code "Inspect this repository, add input validation to auth.py, and run pytest"
                    
                  

                

                

                  Stream a direct prompt response:
                  

                    ornith "Write a lock-free ring buffer in C++20"
                    
                  

                

                

                  Generate an image over the API and save locally to vault.png:
                  

                    ornith image "A futuristic obsidian server vault lit by emerald neon" --size 1024x1024 --out vault.png
                    
                  

                

                

                  Multimodal image analysis:
                  

                    ornith --image screenshot.png "Audit this UI layout and suggest CSS fixes"
                    
                  

                

                

                  Execute Python in the kernel-jailed remote sandbox:
                  

                    ornith sandbox --lang python "import math; print(math.factorial(20))"
                    
                  

                

              


              
Step 4 — Wire Into Claude Code, OpenAI Codex & Aider

              

                

                  Export Ornith environment variables into your current shell:
                  

                    eval "$(ornith env)"
                    
                  

                

                

                  Launch Claude Code powered by Ornith-1.5-35B-Uncensored (/v1/messages):
                  

                    ANTHROPIC_BASE_URL="https://kusi-qwen-api.vercel.app" ANTHROPIC_API_KEY="$ORNITH_API_KEY" claude --model ornith-1.5-35b-uncensored
                    
                  

                

                

                  Launch Aider powered by Ornith-1.5-35B-Uncensored (/v1/chat/completions):
                  

                    OPENAI_BASE_URL="https://kusi-qwen-api.vercel.app/v1" OPENAI_API_KEY="$ORNITH_API_KEY" aider --model openai/ornith-1.5-35b-uncensored
                    
                  

                

              

            

          

        

      


      
      

        

          

            

              

                

                  
Ornith Platform Documentation & API Reference

                  
Drop-in compatible with OpenAI Chat Completions, OpenAI Responses, OpenAI Images, and Anthropic Messages protocols. All data lives locally with masked infrastructure.

                

              


              

                
                
                
                
                
              


              

                
1. CLI Installation & Login — Click Copy to run each step:

                

                  

                    Step 1: Install CLI & export PATH in current terminal
                    

                      curl -fsSL https://kusi-qwen-api.vercel.app/install.sh | bash && export PATH="$HOME/.local/bin:$PATH"
                      
                    

                  

                  

                    Step 2: Authenticate (choose [1] Developer Account via 6-digit Resend code or [2] API Key)

2. OpenAI Python SDK — Authenticate with Authorization: Bearer sk-ornith-... against https://kusi-qwen-api.vercel.app/v1:

                
from openai import OpenAI

client = OpenAI(
    base_url="https://kusi-qwen-api.vercel.app/v1",
    api_key="sk-ornith-YOUR_SECRET_KEY",
)

response = client.chat.completions.create(
    model="ornith-1.5-35b-uncensored",
    messages=[
        {"role": "system", "content": "You are a principal systems engineer."},
        {"role": "user", "content": "Implement a token bucket rate limiter in Python."},
    ],
    temperature=0.6,
    stream=True,
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

              


              

                
How to generate and receive images over the API (3 ways):

                
# 1. Direct OpenAI Images Endpoint (POST /v1/images/generations)
# Returns {"created": ..., "data": [{"url": "https://kusi-qwen-api.vercel.app/files/<id>.png", "b64_json": "..."}]}
curl -s https://kusi-qwen-api.vercel.app/v1/images/generations \
  -H "Authorization: Bearer $ORNITH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A futuristic obsidian server vault lit by emerald neon",
    "size": "1024x1024",
    "response_format": "url"
  }'

# 2. Via Chat Completions (POST /v1/chat/completions)
# When you ask the model to create or edit an image in chat, the response automatically includes:
# - choices[0].message.content: Markdown link ![Generated Image](https://kusi-qwen-api.vercel.app/files/<id>.png)
# - choices[0].message.images: ["https://kusi-qwen-api.vercel.app/files/<id>.png"]
# - top-level "images":        ["https://kusi-qwen-api.vercel.app/files/<id>.png"]

# 3. Via the Ornith CLI
ornith image "A cyberpunk owl perched on a terminal" --out owl.png

              


              

                
Pass images as image_url data URIs or HTTPS URLs. For video files, extract keyframes via POST /api/media/extract-frames or pass --video clip.mp4 in the ornith CLI:

                
curl -s https://kusi-qwen-api.vercel.app/v1/chat/completions \
  -H "Authorization: Bearer $ORNITH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ornith-1.5-35b-uncensored",
    "messages": [{
      "role": "user",
      "content": [
        {"type": "text", "text": "Extract all metrics and layout details from this image."},
        {"type": "image_url", "image_url": {"url": "data:image/png;base64,..."}}
      ]
    }]
  }'

              


              

                
Ornith-1.5-35B-Uncensored executes code inside a Linux kernel Bubblewrap (bwrap --unshare-all) container jail. The model is completely uncensored for all user tasks while strictly blocking any access to host .env files, credentials, SSH keys, or host filesystem paths:

                
# Built-in Autonomous Tools:
# - web_search(query)              : Live web search
# - read_webpage(url)              : SSRF-guarded public webpage reader (blocks file:// & private IPs)
# - run_sandbox_code(language,code): Kernel-jailed container (/workspace, unshared net/fs/pid/env)
# - generate_image(prompt)         : Image synthesis returning public /files/<id>.png URLs
# - edit_image(instruction)        : Image transformation

curl -s https://kusi-qwen-api.vercel.app/api/sandbox/run \
  -H "Authorization: Bearer $ORNITH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"mode": "sandbox", "language": "python", "code": "print(2 ** 64)"}'

              


              

                
Native support for Anthropic POST /v1/messages and OpenAI Responses POST /v1/responses:

                
import anthropic

client = anthropic.Anthropic(
    base_url="https://kusi-qwen-api.vercel.app",
    api_key="sk-ornith-YOUR_SECRET_KEY",
)

msg = client.messages.create(
    model="ornith-1.5-35b-uncensored",
    max_tokens=2048,
    messages=[{"role": "user", "content": "Explain MVCC snapshot isolation."}],
)
print(msg.content[0].text)
